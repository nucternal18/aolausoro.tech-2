# P3.1a — Payload backend + admin + auth cutover — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `payload.config.ts` load, remove Clerk entirely, cut over to Payload native email/password auth with enforced TOTP, and get a working `/admin` against a fresh empty MongoDB — leaving `src/`, `components/admin-route-components/`, and Prisma for P3.2.

**Architecture:** `aolausoro.tech` is a Payload CMS 3.86 + Next.js 16.2 portfolio, mid-migration off Clerk + Prisma + Redux. This sub-project registers the two missing collections (`Categories`, `CVs`) that unblock the config, replaces the custom `clerk` Payload auth strategy with Payload's built-in auth + `payload-totp`, deletes all Clerk code and deps, applies explicit access control across the 10 collections, and adds a `beforeDashboard` stat panel. The layout-builder frontend and the data migration are the separate P3.1b sub-project.

**Tech Stack:** Payload CMS 3.86.0, `payload-totp` 3.0.1, Next.js 16.2.6, MongoDB (Atlas), pnpm 11, Vitest 4, Playwright 1.58, TypeScript 5.9.

**Spec:** `docs/superpowers/specs/2026-09-08-p3.1a-payload-backend-auth-design.md`

export async function BeforeDashboard() {

  const [messages, issues, projects, latestPost] = await Promise.all([
    payload.count({ collection: 'messages', where: { read: { equals: false } } }),
    payload.count({ collection: 'issues', where: { status: { not_equals: 'CLOSED' } } }),
    payload.count({ collection: 'projects' }),

    { label: 'Open issues', value: issues.totalDocs },
    { label: 'Projects', value: projects.totalDocs },
    {
      label: 'Latest post',
      value: post ? post.title : '—',
      sub: post?.publishedAt ? new Date(post.publishedAt).toLocaleDateString() : undefined,
    },
  ]
  return (
    <div className="before-dashboard" style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(160px, 1fr))', gap: '1rem', marginBottom: '2rem' }}>
      {cards.map((c) => (

          <div style={{ fontSize: '1.5rem', fontWeight: 600 }}>{c.value}</div>
          {c.sub && <div style={{ fontSize: '0.75rem', opacity: 0.6 }}>{c.sub}</div>}
        </div>
      ))}
    </div>
  )
}
